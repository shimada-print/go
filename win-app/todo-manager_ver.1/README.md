# ToDo Manager ver.1

---

すること（ToDo）を記録する管理するWindowsのアプリです。入力するとtodo.txtを作成します。WebサイトのToDoでサーバーにデータを保存だと、情報流出もあるので、クライアントソフトにしました。  

goでmain.goをコンパイルしたら「todo-manager.exe」などとリネームし、open_windows-start-up-folder.exeでWindowsのスタートアップフォルダーに、ショートカットを入れておくと、OS起動直後に本アプリも起動するので便利です。
